# GoSalad Website

Live, static restaurant website for **GoSalad** ("pick mix go"), prepared for deployment on GitHub Pages.

## Deployment Instructions

1. Create a repository on GitHub (e.g., `gosalad-website`).
2. Push all the files preserving this exact structure:
   - `index.html` (in root)
   - `favicon.svg` (in root)
   - `css/style.css`
   - `js/script.js`
   - `images/logo.svg`
3. In your GitHub repository, go to **Settings** > **Pages**.
4. Set the **Source** branch to `main` (or `master`) and directory to `/ (root)`.
5. Click **Save**. Your site will be live at `https://<your-username>.github.io/gosalad-website/`.
